# Getting help with Songlass

Use the [issue chooser](https://github.com/cmdr-chara/Songlass/issues/new/choose) for reproducible bugs and feature requests. For a usage or development question, open a short issue explaining what you are trying to do and what you already checked.

Include the app version/build or commit, Android/iOS version, device or emulator, and selected interface style. For playback or lyrics problems, describe the format and timing behavior using a shareable test file or synthetic fixture rather than private music.

For builds and contributions, start with [README.md](README.md#build-and-checks), [CONTRIBUTING.md](CONTRIBUTING.md) and [CLAUDE.md](CLAUDE.md). Platform verification gaps are recorded in [roadmap](docs/ROADMAP.md).

Do not post credentials, account details, personal file paths, full backups or unlicensed third-party material. Crop or redact screenshots and logs before sharing.

- Vulnerabilities: use [SECURITY.md](SECURITY.md).
- Harassment or community concerns: use [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-a-concern).

Describe AI assistance used to prepare an issue as required by the [contribution policy](CONTRIBUTING.md#ai-assistance). Support availability depends on maintainer capacity; there is no guaranteed response time.
